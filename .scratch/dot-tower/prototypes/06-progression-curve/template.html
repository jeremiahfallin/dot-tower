Progression curve, first pass

A headless model of the idle loop — enemy scaling, climber ranks, gold, locking, prestige, the hero, and the floor respawn timer — so the curve can be reacted to rather than argued about. It answers four questions: how long a first run is, where the walls fall, whether run two feels faster, and whether any of it survives floor 1,000. Nothing here is game code; every constant is a slider.

The climb

Floor reached against elapsed time. Vertical ticks are locks.

Minutes spent per 10 floors

Read it as the tower. Bars lengthen as the climb slows; a bar past the wall threshold is where the column piles up and dies.

Locks bought

Sealed income is measured from what the band below the line actually produced in the last 60 seconds, then frozen — ticket 03's rule. A zero means the lock bought no income at all.

Runs

Each row is one run to prestige. Match previous peak is how long the run took to re-reach where the last one stopped — the number that decides whether prestige feels worth it.
